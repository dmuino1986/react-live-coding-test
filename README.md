# React Live Coding Test

## Requirements

- **Node.js 20.19 or later** (recommended: 22 LTS). Check with: `node -v`
- Any IDE you prefer (VS Code, WebStorm, Cursor, etc.)

## Getting started

```bash
git clone <REPO-URL>
cd react-live-coding-test
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

> **No install option:** you can also open this repo directly in the
> browser with StackBlitz: `https://stackblitz.com/github/<user>/<repo>`

The interviewer will walk you through the exercise at the start of the session.
